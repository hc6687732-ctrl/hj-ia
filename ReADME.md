# ⚡ HJ IA — Assistente Inteligente & Tutor Académico

Uma aplicação PWA moderna, com tema escuro e alta performance, construída com Python, Streamlit e a API ultrarrápida da Groq.

---

## 🚀 Funcionalidades Principais

- ** Interface Gemini-Style:** Design moderno em modo escuro com gradientes e estrelas dinâmicas.
- **⚡ Múltiplos Modelos de IA:**
  - **Flash:** Respostas diretas e ultra-rápidas (`llama-3.1-8b-instant`).
  - **Flash Estendido:** Raciocínio complexo e apoio académico (`llama-3.3-70b-versatile`).
  - **Pro:** Resolução avançada de problemas e programação (`deepseek-r1-distill-llama-70b`).
- **🎙️ Mensagens de Voz (Speech-to-Text):** Transcrição automática de áudio usando o modelo **Whisper Large V3**.
- **💳 Modelo Freemium & VIP:** Sistema de tokens gratuitos com opção de desbloqueio ilimitado por **2.000 Kz** (Multicaixa Express) ou **$5,00 USD** (Airtm / PayPal).
- **👑 Modo Criador:** Código de acesso master com tokens infinitos (♾️).

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Python 3.10+
- **Interface:** Streamlit
- **Processamento de Linguagem Natural & Voz:** Groq API (Llama 3.3, DeepSeek R1, Whisper V3)
- **Hospedagem:** Streamlit Cloud
